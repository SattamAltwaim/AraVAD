# VAD Clustering Analysis Notebook

## Overview

The `vad_clustering_analysis.ipynb` notebook performs DBSCAN clustering analysis on the baseline VAD scores generated from the test sentences.

## What it does

1. **Loads baseline VAD scores** from the CSV file generated by the baseline scorer
2. **Applies DBSCAN clustering** to group sentences with similar VAD patterns
3. **Visualizes clusters in 3D space** using the three VAD dimensions
4. **Analyzes cluster characteristics** and shows sample sentences from each cluster
5. **Provides 2D projections** to better understand cluster separation

## Expected Results

Based on the current test data, the analysis typically finds:
- **4 main clusters** representing different emotional patterns
- **~69 noise points** representing outlier sentences with unique VAD patterns
- Clusters ranging from 10-57 sentences each

## Requirements

Install the required packages:
```bash
pip install -r ../requirements.txt
```

## Usage

1. Ensure the baseline VAD scores have been generated by running the baseline scorer script
2. Open the notebook in Jupyter Lab/Notebook
3. Run all cells to see the complete analysis

## Cluster Interpretation

The clusters typically represent different emotional categories:
- **Positive, high-arousal, dominant** (excited, empowered emotions)
- **Negative, high-arousal, submissive** (fear, anxiety, panic)
- **Neutral to positive, low-arousal, balanced** (calm, peaceful states)
- **Negative, low-arousal, submissive** (sadness, depression, despair)

The 3D visualization and sample sentences help interpret what each cluster represents in terms of emotional content.
